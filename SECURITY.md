# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately through [GitHub private vulnerability reporting][private-reporting],
or email [security@jetbrains.com][security-email] and name this repository in the report.
Keep vulnerability details out of public issues, pull requests and discussions until a fix is released.

JetBrains handles reports under its [Coordinated Disclosure Policy][jetbrains-coordinated-disclosure].

## Supported versions

Only the latest release gets security fixes.
